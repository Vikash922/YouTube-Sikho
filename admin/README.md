# YouTube Sikho Academy - Admin Web Management Dashboard

Production administration and operations management portal for **YouTube Sikho Academy**.

---

## 🚀 Key Features

- **Dashboard**: Real-time sales, student enrollment volume, and course performance analytics.
- **Course & Lesson Management**: Curriculum builder, YouTube unlisted video embedder, and pricing manager.
- **Study Materials (PDF / ZIP)**: Secure document and cheat-sheet manager with ephemeral signed URL delivery.
- **Live Streaming Management**: Schedule and broadcast YouTube Live classes with real-time student moderation.
- **Quizzes & Tests**: Canonical MCQ assessment builder with negative marking, time limits, and question ordering.
- **Push Notifications & Broadcasts**: Audience-targeted FCM push notifications and isolated student inboxes.
- **Orders & Refunds**: Real-time transaction history and automated Razorpay refund execution with instant access revocation.
- **Audit & Security Log**: Tamper-evident chronological audit trails for administrative and security actions.
- **Play Store Compliant Data Deletion Portal**: Public verification and deletion request interface.

---

## 🛠 Tech Stack

- **Framework**: React 18, Vite 5, TypeScript
- **Styling**: Tailwind CSS, Lucide React
- **Backend & Database**: Firebase Cloud Firestore, Firebase Auth, Cloud Storage, Firebase Hosting
- **Hosting**: Deployed at `https://sikho-77341.web.app`
